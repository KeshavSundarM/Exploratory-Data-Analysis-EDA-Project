# Task 3 - Exploratory Data Analysis (EDA)

## Employee Performance and Workforce Analysis

This project analyzes employee data to identify patterns, trends, correlations, and factors related to performance and attrition.

### Requirements
```bash
pip install pandas numpy matplotlib
```

### Run
```bash
python eda_analysis.py
```

The program automatically creates a reproducible synthetic dataset and generates statistical summaries, group analysis, correlation analysis, and six visualizations.

See `Task_3_EDA_Report.md` for the complete report.
